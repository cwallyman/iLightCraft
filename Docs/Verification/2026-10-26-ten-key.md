# Tap numeric values for ten-key entry

Editable numeric readouts now open a shared themed ten-key popover. It has
digits, decimal point where supported, sign toggle for signed ranges, backspace,
Clear, Cancel and Done. The full system keyboard does not open. The first digit
replaces the existing value; backspace edits it. Invalid/out-of-range entries
stay in the popup with a range hint. Done validates/snaps to the control's step
and commits once. Cancel/outside dismissal and unchanged Done make no edit.

Coverage: precision Edit/HSL controls, relative WB, generic color/optics/Geometry,
mask and repair controls, overlay opacity, preset/profile Amount, curve Input and
Output, crop angle/custom ratios, red-eye, lens blur, merge output limit, export
quality/long-edge pixels and zoom. Curve coordinates display 0–255 and convert to
normalized points. Existing undo/commit paths and yellow changed-state styling
remain. Zoom preset actions remain available by long-press/context menu.

Read-only capture metadata, photo counts and discrete format choices remain
read-only or choices; they are not free numeric editing controls. Source photos
and the engine are unchanged. No simulator or automated tests run.

Device build/sign/install evidence: LocalVerification/ten-key-*.
Manual acceptance: enter a signed fractional Exposure, a mask value, Geometry,
Amount, a curve point, custom crop ratio, export pixel size and zoom; check Cancel,
outside dismissal, bounds errors, yellow/reset states and one-step Undo.

Delivery: device build and strict signature verification passed. Installation
on the iPad succeeded, sequence 2732. The app was not launched.
